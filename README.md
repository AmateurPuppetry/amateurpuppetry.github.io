# アマチュア人形劇の薦め

アマチュア人形劇の魅力を紹介する静的サイトです。全6ページ（トップ／芸術／誰でも／仲間と観客／家族と地域／始め方）。

- 元の公開先： https://lboo.jp/mb/
- このリポジトリは、ドメインやレンタルサーバーの契約に左右されず長く残すための GitHub Pages 版です。
- 構成：HTML＋CSS＋画像のみ（サーバー側のプログラムなし）。相対リンクのみで作られているため、どのURL階層でもそのまま表示できます。
- `.nojekyll` を置いているため、Jekyll変換を受けずファイルがそのまま配信されます。

## 更新方法
ファイルを編集してコミット（push）すると、数分で GitHub Pages に反映されます。
